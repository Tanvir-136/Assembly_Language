Welcome! 👋  
This repository is a collection of small, focused 8086 Assembly programs—my personal learning notes as I explore how computers truly work at the hardware level.  
All programs are created and tested using **emu8086**.

## 🛠️ How to Run

1. Open **emu8086**  
2. Copy any `.asm` file into the editor  
3. Click **Run**  
4. Watch the registers update and enjoy the low-level magic! ✨
