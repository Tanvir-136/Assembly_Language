Welcome! 👋

This repository is my digital notebook for learning 8086 assembly. It's a collection of small, fundamental programs, each one a building block in understanding how computers really work.

Everything here was crafted for and tested on the mighty emu8086 emulator.

🚀 What's Inside?

I've grouped my experiments by what they taught me. Click on any category to expand it!

<details>
<summary><strong>📺 1. The Basics: Talking to the Screen</strong></summary>

Print a String: The classic "Hello, World!" program.

Print a Message (The Hard Way): A small program that prints a message using both individual characters ('H') and their ASCII-code equivalents (72).

</details>

<details>
<summary><strong>📦 2. Moving & Swapping Data</strong></summary>

Exchange AX and BX: Using the XCHG instruction to instantly swap the contents of two registers.

</details>

<details>
<summary><strong>🧮 3. Core Arithmetic</strong></summary>

Add/Subtract 16-bit Numbers: Simple addition and subtraction, including handling the borrow flag.

Multiply 16-bit Numbers: Using the MUL instruction to perform 16-bit multiplication.

</css>

<details>
<summary><strong>🔄 4. Number System Conversions</strong></summary>

Binary to Decimal: A program to turn a binary number into one we can read.

Decimal to Binary: A program that does the reverse, turning a base-10 number into base-2.

BCD (Binary Coded Decimal):

Add two 8-bit BCD numbers

Subtract two 8-bit BCD numbers

</details>

<details>
<summary><strong>💡 5. Fun with Algorithms</strong></summary>

Find the Factorial: A classic loop-based program to calculate n!.

Generate the Fibonacci Series: Creating the famous sequence where F(n) = F(n-1) + F(n-2).

Find the Square Root: An integer square root algorithm that finds the root of a number by subtracting successive odd numbers.

</details>

🛠️ How to Use

All programs are self-contained and ready to run.

Fire up the emu8086 emulator.

Copy the code from any .asm file.

Paste it into the emulator's code editor.

Click "Run" and watch the magic happen in the registers!
